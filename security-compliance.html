Cyber Security Framework

Security & Technical Compliance

AES-256 Vault Cloudflare DDOS Shield NPCI UPI Verified

At BOOYAH SPORTS, player security, transactional integrity, and data protection form the foundation of our gaming engine. We implement military-grade encryption and real-time threat intelligence to protect 100,000+ esports gamers in India.

TLS 1.3 & AES Encryption

All network calls between the Android APK and cloud database servers are secured with TLS 1.3 protocol and AES-256 bits payload encryption.

NPCI / RBI Compliance

Instant UPI payouts run through PCI-DSS Level 1 compliant gateway partners, safeguarding user financial data without storing CVVs or PINs.

Anti-DDoS & Firewall

Enterprise Cloudflare protection mitigates volumetric DDoS attacks, automated bot registration spam, and unauthorized API probing.

AI Anti-Cheat Engine

Proprietary spectral match verification audits kill timestamps and placement logs to permanently purge hackers and modded client accounts.

Information Security Management

Our infrastructure follows ISO/IEC 27001 guidelines for information security management systems (ISMS):

  • Role-Based Access Control (RBAC): Admin dashboard access requires multi-factor authentication (MFA) and strict IP Whitelisting.
  • Zero Data Monitization: User metrics, phone numbers, and match records are never monetized or exposed to ad networks.
  • Vulnerability Disclosure Program: Ethical hackers and security researchers can report vulnerabilities to security@booyahsports.in for bounty review.
